## 当前实现

- 原始 README 保留在本文件夹的 README.upstream.md；原始界面可从 Fork 历史恢复。
- 定制「观星」首页，公历生日、准确钟点、排盘性别、出生地录入。
- 北京时间默认、真太阳时可选、夏令时手动扣除、晚子时换日可选；均保留原始输入与换算说明。
- 十二宫、十四主星、辅星、亮度、生年四化、三方四正，大限 / 流年四化叠加。
- 依据实际星曜的原创文化象义解读、空宫借对宫说明。同时提供千问真实 AI 详批，不使用上游未公开断语库。
- 十四主星百科；三部公版古籍、章节阅读与浏览器全文搜索。
- 命盘仅手动保存到当前设备；支持读取、删除和 Markdown 导出。
- /heming 提供双盘命宫并排阅读，不打关系分数。

## 核心模块研读

`lib/ziwei/algorithm.ts` 通过 iztro 排盘，在装配阶段统一星曜亮度，采用农历正月初一换年；节气四柱与紫微农历口径分别保留。`true-solar-time.ts` 计算经度差与均时差，并输出跨日偏移；`resolveZiweiDayOffset` 负责晚子时换日。`dst-cn.ts` 采用上游通行日期表，仅用于提示；历史交界日期存在流派及时间数据库口径差异，用户需确认当年实际钟表制。`patterns.ts` 提供传统格局规则；`sihua.ts` 与 `TimeNav` 提供四化映射。古籍数据保留于 `lib/classics/`。

新增 `lib/guanxing/birth.ts` 统一校验与时间换算；`reading.ts` 根据实际主星、对宫和宫位生成可追踪说明。出生地输入明确限中国大陆北京时间；不自动推断农历、海外时区或时辰不详。

## 独立数据集

GitHub Fork 不复制 Release 附件，因此另提供 `.github/workflows/mirror-releases.yml` 和 `scripts/mirror-releases.py`。工作流遍历上游每个 Release、每个附件，复制后核对文件长度及 SHA256。已复制且 hash 一致的附件会跳过，失败后可手动重新运行。v4 全年总包和 77 个分年包均保留；v3 三个约 2 GB 的分卷及校验文件也全部镜像。不会在本机展开约 90 GB 的数据。

大型数据集未载入网站运行时。上游商业断语库、AI 提示词、后端接口、登录支付和原商业站界面不在开源范围，无法通过复制获得。当前版本没有任何不可用的 AI 解读按钮。

## 本地运行与部署

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run start
# 发布到自己的 Cloudflare 账号
npm run deploy
```

网站采用 Vinext + Cloudflare Workers，配置在 `wrangler.jsonc`，构建产物为 `dist/client` 和 `dist/server`。访问不需要 ChatGPT 账号；密钥仅在 Worker Secret 中保存。`dist`、`node_modules`、环境变量和凭据不进 Git。详见 [Cloudflare 部署说明](cloudflare-deployment.md)。
